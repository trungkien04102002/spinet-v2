\section{Caveats}

\begin{itemize}
\item \textbf{Single seed (42)} --- multi-seed deferred. Gap Hybrid vs
Baseline $+0.011$ F1 nằm trong noise zone, cần $\geq 3$ seed để
khẳng định.
\item \textbf{Modic Type 1/3}: 0\% recall ở tất cả config --- class
quá rare ($<5\%$/$<1\%$). Sẽ cải thiện với BiomedCoOp prompt tuning
hoặc Mendeley augmentation (future work).
\item \textbf{BMC-only converge sớm ep 11/15} --- early stop có thể bị
local optimum, cần fair comparison với linear-probe naked BiomedCLIP
(future work).
\end{itemize}
